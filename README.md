# Cricket Auction Porbandar

Clean Android demo project using Java + Android SDK views (no Compose/Kotlin dependencies).

## GitHub Actions
1. Upload the whole `CricketAuctionPorbandar` folder to the repository root.
2. Open **Actions** → **Build Cricket Auction APK**.
3. Run workflow.
4. Open the green run and download `CricketAuctionPorbandar-debug-apk` from Artifacts.

This build is a demo/offline auction UI. Payment gateway, authentication, cloud realtime sync and production security still need backend implementation.
